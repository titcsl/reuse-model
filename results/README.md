# Derived results

These files are regenerated by `python reproduce.py`. The pilot and follow-up remain separate throughout the analysis.

| Files | Purpose |
|---|---|
| `followup_trials.csv`, `pilot_trials.csv` | Completed-trial timing and energy summaries |
| `*_pairs.csv`, `*_descriptive_pairs.csv` | Matched policy contrasts and descriptive summaries |
| `followup_sweep_pairs.csv`, `followup_sweep_fits.csv` | Polling-interval comparisons and descriptive fits |
| `followup_control_pairs.csv` | No-launch and copy-control comparisons |
| `followup_power_fields.csv` | Explicit NVML power-field comparisons |
| `*_aa_pairs.csv` | Identical-workload comparisons |
| `*_queries.csv`, `*_fields.csv` | Acquisition-query and field diagnostics |
| `*_protocol.json` | Fixed acquisition protocols recovered from the logs |
| `*_audit.json`, `audit_summary.json` | Completion, correctness and integrity checks |
| `timing_components.csv`, `paper_numbers.json` | Values used in the manuscript |
| `package_validation.json` | Source, plan, workload-trace and headline-count verification |

The principal follow-up checks are 144 completed trials, 1,788 correctness comparisons, 144 final-image checks and 10 opposite signs among 36 main-policy contrasts. Contrasts share a baseline within each block; individual frames are not independent experimental replications.

Generated TeX tables remain local outputs rather than committed manuscript source.
