# Generated figures

The PNG files are generated from the archived follow-up by `render_results.py`.

- `polling_and_pairs.png`: polling-frequency behavior and matched main-policy energy comparisons.
- `counter_read_count.png`: the counter-read-count diagnostic.

Running `python reproduce.py` also generates vector PDF copies locally. All plotted values come from the derived result files; the figures do not provide external calibration of either estimator.
